# Hotel Reservas - Projeto Full Stack

## Tecnologias:
- IDE: Vs Code;
- SGBD: MySQL2;
- Servidor de aplicação: Node.js;
- Linguagens utilizadas: SQL, JavaScript, HTML e CSS.

## Como Executar:

1. Criar banco hotel_db

2. Instalar dependências

- npm install

3. Gerar Prisma

- npx prisma generate

4. Executar migrações

- npx prisma migrate dev

5. Iniciar API

- npm run dev

6. Abrir index.html
